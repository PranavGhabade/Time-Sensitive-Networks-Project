# Time-Seneitive-Networks-Project

## Overview

Modern cyber-physical systems such as industrial automation, autonomous systems, smart infrastructure, and real-time control networks require deterministic communication where data packets must arrive within strict latency and reliability bounds. Traditional Ethernet networks operate on a best effort basis and cannot guarantee such timing constraints.

Time-Sensitive Networking (TSN) is a collection of IEEE standards that enhances Ethernet with deterministic capabilities. These standards introduce mechanisms for precise time synchronisation, traffic prioritisation, scheduled transmission, and bounded latency communication. As a result, TSN enables Ethernet networks to support applications that require predictable timing behaviour.

Although TSN has achieved significant success in wired Ethernet environments, extending deterministic guarantees to wireless communication remains an open research challenge. Wireless mediums introduce additional uncertainties due to interference, channel contention, signal attenuation, and dynamic link conditions. These factors make it difficult to maintain strict timing guarantees when traffic traverses wireless links.

This research focuses on understanding how deterministic communication can be maintained in hybrid networking environments that combine wired TSN infrastructure with wireless communication technologies. The goal is to evaluate how scheduling mechanisms, traffic prioritisation, and synchronisation techniques behave when deterministic traffic flows across heterogeneous communication mediums.

In addition to traditional networking mechanisms, the research also explores the integration of machine learning techniques for intelligent network management. Deep Reinforcement Learning (DRL) is investigated as a potential approach for adaptive scheduling and optimisation in dynamic network conditions. By learning from network state observations such as delay patterns, queue behaviour, and channel quality, intelligent agents may assist in improving scheduling efficiency and maintaining deterministic performance.

This work aims to bridge the gap between deterministic wired networking and emerging wireless communication environments, contributing towards the development of next generation communication systems capable of supporting latency critical and reliability sensitive applications.

## Research Motivation

Future networked systems such as autonomous vehicles, industrial robotics, remote control systems, and intelligent infrastructure require communication networks that are both reliable and predictable. As these systems increasingly rely on wireless connectivity, maintaining deterministic behaviour across hybrid wired and wireless networks becomes a critical research problem.

Understanding how scheduling strategies, synchronisation mechanisms, and intelligent optimisation techniques interact in such environments is essential for designing communication architectures that meet the strict requirements of modern real time applications.

## Key Concepts

The research draws upon several important networking concepts and standards including:

- Time-Sensitive Networking (TSN)
- Deterministic Ethernet communication
- Network wide time synchronisation
- Traffic prioritisation and scheduling
- Hybrid wired and wireless communication
- Intelligent network optimisation using machine learning

## Research Direction

This project investigates deterministic communication in hybrid networking environments and studies how advanced scheduling and optimisation techniques can improve latency, reliability, and timing predictability in complex network conditions.
